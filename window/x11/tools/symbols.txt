# window/x11/tools/symbols.txt — the contract.
#
# One line per symbol this directory commits to binding: "<soname> <name>".
# check_symbols.sh compares three sets against each other — what bind/*.cst
# declares, what this file lists, and what the local shared objects export —
# and a binding that drifts from this file fails the build.
#
# It exists because "all 774 of libX11" is a claim that has to stay true over
# time rather than at one moment. Without a manifest, a function quietly
# dropped during a refactor is indistinguishable from one that was never
# there.
#
# Derived from the shared objects on this machine with:
#   nm -D --defined-only <so> | awk '$2=="T"{print $3}'
# libX11 excludes the 407 _X* symbols, which are libX11's private
# implementation rather than API. libXext lists only the MIT-SHM entry
# points; the other 122 belong to extensions this layer does not present
# (shape, dbe, sync, dpms), and adding them is additive rather than a
# correction.
#
# Four libX11 exports have no declaration in any shipped public header:
# KeySymToUcs4, read_EncodingInfo, _Utf8GetConvByName and XkbTranslateKey
# (XKBlib.h declares XkbTranslateKeyCode and XkbTranslateKeySym, not this).
# They are listed here because the .so exports them and the count in
# ../../window.md is 774, but binding them would mean inventing a prototype,
# and a wrong one is silent corruption. So 770 of the 774 are bound and these
# four are named rather than left as a silent gap.
#
# libXfixes has one of the same kind: XFixesFindDisplay is exported but declared
# only in the private Xfixesint.h. 37 of its 38 are bound.
